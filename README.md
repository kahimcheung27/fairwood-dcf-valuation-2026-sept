# Fairwood Holdings DCF Valuation Project
**Project Overview:**

A data-driven financial analysis leveraging **Python** and **Excel** to extract and clean the financial datasets from official Financial earnings report. This project evaluated the intrinsic firm value of Fairwood Holdings via a **2-stage Free Cash Flow to Firm (FCFF) Discounted Cash Flow (DCF) Valuation model** with a 5-year explicit forecast horizon.

**Objectives:**
  - **Performance Benchmarking:** Investigate Fairwood Holdings' competitive position using **Comparable Company Analysis** automated by **Python**
  - **Valuation:** Perform objective **DCF Firm Valuation** and report the insights similar to professional **Advisory reports** 

**Technical skills used:**
  - **Data Extraction:** Excel (from Bloomberg Terminal and official Financial earnings report)
  - **Data Cleaning:** Python (Pandas)
  - **Comparable Company Analysis:** Python (Pandas, Openpyxl) (automate the calculation of financial ratios and Excel spreadsheets professional report formatting)
  - **DCF Valuation:** Excel

**Repository Structure:**
  ```
  ├── notebooks/      # Python source code and cleaning logic (.ipynb)
  ├── outputs/        # Processed data outputs (.xlsx)
  ├── reports/        # Summary Report (.pdf)
  └── README.md       # Project Documentation
```

**Key findings:**

The Total Firm Value is valued at $11.7 billion, including the projected Free Cash Flow to Firm (FCFF) ranges from $451 million (FY2027) to $494 million (FY2031), driven by strategic GBA fast-food restaurant business expansion.
